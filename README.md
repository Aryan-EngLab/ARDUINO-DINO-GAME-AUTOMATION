# Arduino Dino Game Automation using LDR

An Arduino project that uses a Light Dependent Resistor (LDR) and a servo motor to automate the Chrome Dino Game.

## 🔗 Live Tinkercad Simulation

[Open the circuit and try the simulation](https://www.tinkercad.com/things/7v3BByvkaa1-dino-game-automation?sharecode=fQztfZlhYK9Ote2niirH2G-9UdX6v26VbsG26KaaK8U)

## 🧰 Components Used

- Arduino Uno
- LDR (Photoresistor)
- Resistor
- Servo motor
- Breadboard
- Jumper wires

## ⚙️ How It Works

1. The LDR detects changes in light intensity.
2. The Arduino reads the sensor value.
3. The program compares the reading with a threshold.
4. The servo motor moves according to the programmed condition.
